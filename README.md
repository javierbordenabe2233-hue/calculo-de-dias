# Cálculo de días

Calculadora de días entre fechas, instalable en el celular o la compu (PWA) y que funciona sin internet.

- **2 fechas:** días totales, desglose en años/meses/días, semanas, días hábiles y horas.
- **Varias fechas:** suma de varios pares de fechas y cuántos días quedan de un plazo (90, 60 u otro).

## Cómo instalarla

Abrí la app: **https://javierbordenabe2233-hue.github.io/calculo-de-dias/**

- **Android (Chrome):** menú ⋮ → *Instalar app* / *Agregar a pantalla principal*.
- **iPhone (Safari):** botón Compartir → *Agregar a pantalla de inicio*.
- **PC (Chrome/Edge):** ícono de instalar en la barra de direcciones.

También podés descargar el ZIP (*Code → Download ZIP*) y abrir `index.html`.
